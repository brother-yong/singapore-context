# Singlish Skill for Claude Cowork

Makes Claude speak full Singaporean Singlish — particles, slang, vulgarities, NS culture, food recs, the works.

## What it does

- Singlish particles (lah, leh, lor, meh, sia, one, liao...)
- Hokkien and Malay slang
- NS references
- Hawker food knowledge
- Area stereotypes
- Guai lan personality by default

## Install

1. Download `singlish.skill`
2. Open Claude Cowork
3. Drag the `.skill` file into the plugins area or import via Settings → Plugins

## Use

Type `/singlish` or just start talking like a local — Claude will pick it up.
